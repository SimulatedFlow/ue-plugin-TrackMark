# Store Art

Fab listing images for TrackMark. Produced in Phase 3 from the demo map, at the sizes Fab asks for.

## Required

| File | Size | What it must show |
|---|---|---|
| `Featured.png` | 1920 × 1080 | The demo running: walkers laying trails, the stats box showing the draw call count next to a four-figure mark count |
| `Thumbnail.png` | 1920 × 1080 | A tight shot of trails across the three surfaces |
| `Gallery-01.png` … | 1920 × 1080 | See below |

## Gallery shots to capture

1. **The draw call claim.** Two thousand marks on screen, stats box reading one draw call per profile.
   This is the whole pitch in one image.
2. **The budget.** Same scene after dropping the budget from 2048 to 256 — the count fallen, the draw
   calls unchanged, `recycled` climbing and `allocated` flat.
3. **The ramp.** Prints lying along a slope, following it rather than sinking into it horizontally.
4. **Three surfaces.** Grass → sand → snow in one shot, with the shape and opacity visibly different.
5. **The four profiles.** Boot, Paw, Tyre and Track trails side by side.
6. **The control panel.** The Canvas overlay with its buttons, so buyers can see there is something to
   click.

## Rules

- Real screenshots from the packaged demo. No mock-ups, no composites, no numbers typed over the top.
- The stats box must be legible at thumbnail size, because the numbers are the product.
- No local file paths, editor chrome, or e-mail addresses visible in any shot.

`Icon128.png` for the `.uplugin` lives in `Resources/`, not here.
